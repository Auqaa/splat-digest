# Настройка с нуля (без установки чего-либо на компьютер)

Займёт около 15 минут. Понадобятся три значения:

| Что | Откуда | Как выглядит |
|---|---|---|
| Токен бота | Telegram, @BotFather | `7123456789:AAH...` |
| ID вашего чата | Telegram, через браузер | `123456789` |
| Ключ DeepSeek | platform.deepseek.com | `sk-...` |

**Ни токен бота, ни ключ DeepSeek никому не показывайте и не вставляйте в код.** Они хранятся только в
GitHub Secrets.

---

## Шаг 1. Создать бота в Telegram

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите **Start**.
2. Отправьте `/newbot`.
3. Введите имя бота, любое, например `3DGS Digest`.
4. Введите username бота. Он должен заканчиваться на `bot` и быть свободным, например `my_3dgs_digest_bot`.
5. BotFather пришлёт сообщение с токеном вида `7123456789:AAH...`. Скопируйте его целиком.
   Если токен утёк, отправьте BotFather `/revoke` и получите новый.

## Шаг 2. Узнать ID своего чата

1. Откройте своего нового бота (ссылка `t.me/<username>` есть в сообщении BotFather) и нажмите **Start**.
   Затем напишите ему любое сообщение, например `привет`.
2. В браузере откройте адрес, подставив свой токен **вместо `ТОКЕН`** (слово `bot` перед токеном оставьте):
   ```
   https://api.telegram.org/botТОКЕН/getUpdates
   ```
3. На странице найдите фрагмент `"chat":{"id":123456789`. Число после `"id":` и есть ваш ID чата.
   - Если там `{"ok":true,"result":[]}`, напишите боту ещё одно сообщение и обновите страницу.
   - Если `{"ok":false,"error_code":401...}`, токен вставлен с ошибкой.

## Шаг 3. Ключ DeepSeek

1. Зайдите на https://platform.deepseek.com и зарегистрируйтесь.
2. Пополните баланс в разделе **Top up**. Боту нужно примерно $2–4 в месяц, так что $5–10 хватит надолго.
   **Без баланса API не работает.**
3. Откройте **API Keys**, нажмите **Create new API key** и скопируйте ключ `sk-...`.
   Ключ показывают **один раз**. Если не успели скопировать, удалите его и создайте новый.

## Шаг 4. Секреты на GitHub

1. Откройте репозиторий на GitHub и перейдите в **Settings** (вкладка с шестерёнкой сверху).
2. В меню слева выберите **Secrets and variables → Actions**.
   ⚠️ Нужен именно пункт **Actions**. **Codespaces**, **Agents** и **Dependabot** не подходят: бот секреты оттуда не увидит.
3. На вкладке **Secrets** нажмите **New repository secret** и создайте три секрета.
   Имена должны совпадать **буква в букву**:

   | Name | Secret |
   |---|---|
   | `LLM_API_KEY` | ключ DeepSeek `sk-...` |
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `TELEGRAM_CHAT_ID` | число из шага 2 |

   Значение вставляйте без кавычек и пробелов. Сохраните каждый секрет кнопкой **Add secret**.
   Потом значение посмотреть уже нельзя, только перезаписать. Это нормально.

Необязательные секреты, их можно добавить позже: `S2_API_KEY` (Semantic Scholar), `BLUESKY_HANDLE` и
`BLUESKY_APP_PASSWORD`. `GITHUB_TOKEN` создавать **не нужно**: GitHub подставляет его сам.

## Шаг 5. Первый запуск

1. Откройте вкладку **Actions** вверху репозитория.
   Если там написано, что workflows отключены, нажмите зелёную кнопку **I understand my workflows, go ahead and enable them**.
2. Слева выберите **daily-digest**.
3. Справа нажмите **Run workflow**, в списке **command** выберите команду и снова нажмите зелёную **Run workflow**.
   Запустите команды по очереди, каждый раз дожидаясь зелёной галочки (1–3 минуты):

   | № | command | Зачем |
   |---|---|---|
   | 1 | `check-sources` | показывает, какие источники работают; в Telegram ничего не придёт |
   | 2 | `seed` | помечает всё уже опубликованное как прочитанное; **без этого первый дайджест придёт огромным** (недели статей) |
   | 3 | `run` | отправляет дайджест; после `seed` он будет почти пустым, но так видно, что бот работает |

4. Чтобы посмотреть результат, нажмите на запуск в списке, затем на **digest**, затем раскройте шаг
   **Run splat-digest ...**.

После этого бот будет присылать дайджест **каждый день около 07:23–08:30 по Москве**.
GitHub запускает расписание с опозданием, это нормально.

## Если что-то не так

| В логе / в Telegram | Причина и что делать |
|---|---|
| `Не заданы переменные окружения: ...` | секрет не создан или имя с опечаткой; секреты лежат не в **Actions** |
| `LLM: неверный LLM_API_KEY (401)` | ключ DeepSeek с ошибкой или удалён: создайте новый и перезапишите секрет |
| `HTTP 402` / `Insufficient Balance`, в дайджесте «не обработано LLM: N» | пополните баланс DeepSeek |
| `Telegram sendMessage failed: 400 ... chat not found` | неверный `TELEGRAM_CHAT_ID`, или вы не нажали **Start** у бота |
| `Telegram ... 401 Unauthorized` | неверный `TELEGRAM_BOT_TOKEN` |
| в шапке дайджеста ⚠️ `Reddit: ... 403` | Reddit блокирует серверы GitHub, это ожидаемо (см. ниже) |
| дайджест не пришёл, в Actions ничего нового | в публичном репозитории GitHub отключает расписание после 60 дней без коммитов: откройте Actions → daily-digest → **Enable workflow** |

## Настройки без кода

**Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**:

| Name | Пример | Что делает |
|---|---|---|
| `MIN_RELEVANCE` | `6` | порог «релевантно» (по умолчанию 5) |
| `SOURCES` | `arxiv,hf_daily,s2,openreview,github_releases,github_repos,awesome,vendors,hn,bluesky` | какие источники включены; например, без `reddit` и `hf_hub` |
| `DEEP_READ` | `0` | выключить чтение полного текста статей |

Список репозиториев и сайтов компаний лежит в файле `sources.toml`. Его можно править прямо на GitHub:
откройте файл, нажмите ✏️ и затем **Commit changes**.
